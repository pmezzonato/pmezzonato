# Brand assets

The ghost mark, in the profile's palette — near-black `#14120F` and amber `#E4B33C`.

## Which file to use where

| Use | File |
|---|---|
| GitHub / social avatar (shown as a circle) | `avatar-512.png` — ghost sits safely inside any circular crop |
| High-res avatar (print, large displays) | `avatar-1024.png` |
| Smaller avatar slots | `avatar-400.png`, `avatar-256.png`, `avatar-128.png` |
| Ghost on your own background (slides, banners) | `ghost.svg` or `ghost-1024.png` / `ghost-512.png` (transparent) |
| Website favicon (scalable) | `favicon.svg` |
| Classic favicon | `favicon.ico` (16/32/48/64 in one file) |
| Apple touch icon | `favicon-180.png` |
| PNG favicons | `favicon-32.png`, `favicon-16.png` |

## Editing

`avatar.svg`, `ghost.svg` and `favicon.svg` are the masters — vector, so they
scale to any size. The PNGs were rendered from them. If you change a master,
re-render the PNGs rather than editing them by hand.

## Colours

- Background / eyes: `#14120F`
- Ghost: `#E4B33C`
